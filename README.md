# Return Offer Rates

A platform for tracking and sharing return offer statistics for tech companies. Users can submit their internship return offer experiences and view aggregated statistics.

## Features

- 🏢 **Company Search** - Search for companies and view their return offer rates
- 📊 **Top Companies** - Browse companies ranked by submissions, best rates, and worst rates
- 📝 **Submission Form** - Submit your return offer experience (data remains anonymous)

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Database:** Supabase
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI
- **Data Fetching:** TanStack Query
- **Language:** TypeScript
